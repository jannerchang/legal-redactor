# 全文 LLM 输出必须是有界单行 JSON

全文实体登记必须把“提示词要求单行紧凑 JSON”“全文调用发送换行停止序列 `stop="\n"`”以及“仅对确属截断的 JSON 做不虚构实体文本的结构闭合”视为同一个不可拆分的生成协议。Qwen 3.5 曾在已经生成完整登记 JSON 后继续输出，导致请求耗尽 8,192-token 预算或在 240 秒超时；单独保留较大 token 预算、单独增加超时或只依赖提示词都不能可靠终止生成。未来重构模型调用、提示词、结构化输出或模型适配器时，必须保留并通过测试验证这三个约束；若替换停止机制，须先用真实长文证明新机制能在完整 JSON 后立即返回且不会在 JSON 内部截断。

## Consequences

- 全文初次登记、JSON 修复和二次补漏必须继续输出单行 JSON，不得引入 Markdown 代码块、解释、证据字段或格式化换行。
- `stop="\n"` 只适用于上述单行协议；修改提示词为多行输出会把换行停止序列变成提前截断错误。
- 截断修复只能闭合已有 JSON 结构，不能补写、猜测或规范化任何实体文本。
- 回归测试必须同时覆盖请求体中的换行停止序列、单行提示词约束，以及截断修复不虚构实体。
